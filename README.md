# research-agent

Исследовательский агент на LangGraph. Он строит план запросов, ищет через Brave Search API, читает страницы через trafilatura и пишет отчёт со ссылками. Отчёт принимается, только если каждая ссылка в нём ведёт на страницу, которую агент реально открыл.

## Как это работает

```
вопрос → план → поиск → чтение страниц → проверка полноты ─┐
                  ▲                                         │ мало данных (до 3 кругов)
                  └─────────────────────────────────────────┘
                                   │ хватает
                                   ▼
                      черновик → проверка ссылок → report.md
                          ▲             │
                          └─ 1 повтор ──┘  (второй плохой черновик → отказ)
```

1. **План.** Модель делает из вопроса 3–6 поисковых запросов.
2. **Поиск.** Brave Search API возвращает адреса. Повторы агент убирает.
3. **Чтение.** trafilatura достаёт основной текст. Удачно открытые страницы попадают в реестр (S1, S2…).
4. **Проверка полноты.** Модель решает, хватает ли материала. Если нет, она предлагает новые запросы. Кругов не больше трёх, страниц не больше 15.
5. **Черновик.** Модель ссылается только номерами вида `[S3]`. Адреса подставляет программа.
6. **Проверка ссылок.** Это обычный код, без модели. Он отклоняет отчёт, если в нём нет ссылок, есть номер не из реестра или есть адрес, которого агент не открывал.

## Защита от инструкций внутри страниц

- Текст страницы идёт модели внутри тегов `<untrusted_source>` как данные. Правила лежат отдельно, в системной инструкции.
- Теги с таким именем внутри страницы агент удаляет, поэтому страница не может «закрыть» данные раньше времени.
- Агент не переходит по ссылкам из текста страниц. Новые адреса приходят только из Brave.
- Агент не открывает локальные и приватные адреса (`localhost`, `192.168.…`), в том числе через переадресацию.
- Даже если модель поддастся на уловку, проверка ссылок отклонит чужой адрес.

Ограничения: проверка не ловит голое имя сайта без `https://` в обычном тексте. Она не проверяет, правдив ли факт на странице.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
export BRAVE_API_KEY=ваш_ключ
export ANTHROPIC_API_KEY=ваш_ключ
.venv/bin/python -m research_agent "ваш вопрос"
```

Результат: `report.md`. Если отчёт отклонён, файла нет, а причины печатаются в stderr (поток ошибок). Параметры: `--out`, `--max-pages`, `--max-rounds`. Модель по умолчанию — `claude-sonnet-5-5`, её можно сменить переменной `RESEARCH_MODEL`.

## Тесты

```bash
.venv/bin/python -m pytest -q
```

Тесты не ходят в интернет: Brave, страницы и модель в них заменены подделками.
